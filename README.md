# Investor Olympics 投资奥运会

A classroom investment game for Class 3 (Multiplicity) of the design-driven entrepreneurship course, based on *A Design-Driven Guide for Entrepreneurs* (Routledge, 2023).

Teams act as investment funds with ¥10 million over five fictional years. Each year shows four ventures with a mini Sustainable Business Canvas and three STEEP signals; an event then re-prices every venture. Strategy points reward diversification, impact, unit economics, resilience and reserves, and penalize traps. A Debrief tab rebuilds the whole class's choices for a live discussion.

Live site: https://www.josephpress.com/investor-olympics/

- `index.html`: the game (English and Chinese)
- `config.js`: Tencent CloudBase settings for live results (optional)
- `SETUP.md`: deployment and classroom steps

All ventures are fictional. Numbers are illustrative.
